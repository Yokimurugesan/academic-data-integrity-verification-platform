\# Academic Data Integrity Verification Platform



\## Project Structure



client - Frontend

server - Backend (Node.js + Express + MySQL)



\## Backend Setup



cd server

npm install

npm start



\## Frontend Setup



cd client

npm install

npm run dev



\## Environment Variables



Create a .env file inside server folder:



PORT=5000

DB\_HOST=localhost

DB\_USER=root

DB\_PASSWORD=yourpassword

DB\_NAME=academic\_db
